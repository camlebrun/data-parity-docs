# data-parity-docs

Documentation site of [data-parity](https://github.com/camlebrun/data-parity), built with
[Starlight](https://starlight.astro.build) (Astro). Published at https://camlebrun.github.io/data-parity-docs/.

## Run locally

```bash
npm ci
npm run dev       # dev server
npm run build     # static site in dist/ (fails on broken internal links)
npm run preview   # serve dist/
```

## Contribute

Pages live in `src/content/docs/` (Markdown/MDX). Open a pull request; the build must pass.
